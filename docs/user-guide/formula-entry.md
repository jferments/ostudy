# Enter and edit mathematical formulas

Use the **Insert or edit formula** button in the rich card editor's toolbar to insert mathematical notation. To change an existing formula, select it and choose the same button, double-click it, or press Enter while it is selected. oStudy stores validated formula source and renders it locally; you do not need to know LaTeX to use the visual editor.

## Use the graphical controls

The **Edit formula** dialog opens with a formula field and a **Formula tools** panel. Choose a category:

- **Structures** — fraction, square, power, square and nth roots, subscript, absolute value, parentheses, brackets, braces, and a 2 × 2 matrix.
- **Symbols** — plus or minus, multiplication and division signs, infinity, pi, degrees, partial, and nabla.
- **Relations** — equality, inequalities, approximation, arrows, and set membership.
- **Greek** — common lowercase and uppercase Greek letters.
- **Calculus** — derivatives, integrals, sums, and limits.

Select an expression in the formula field before pressing a structure button when you want to wrap that expression. For example, select `x² + 7x + 3` and press **Fraction**. The selected expression becomes the numerator and the cursor moves to the denominator placeholder; no parentheses are added around the numerator.

The same selection behavior works for **Square**, **Power**, **Square root**, **Nth root**, **Subscript**, **Absolute value**, **Parentheses**, **Brackets**, and **Braces**. When there is no selection, the structure is inserted with empty placeholders to fill in.

Use **Tab** and **Shift+Tab** to move between placeholders. The keyboard button in the corner of the formula field (**Show math keyboard**) opens a larger on-screen math keyboard when you need symbols or layouts that the Formula tools panel does not have.

## Keyboard shortcuts

On a device with a keyboard, **Shortcuts & help** in the Formula tools panel shows this reference.

| Keys | Action |
| --- | --- |
| `/` | Create a fraction from the selection or preceding expression |
| `^` | Start a superscript/exponent |
| `_` | Start a subscript |
| `Alt+V` | Square root |
| `Alt+Shift+V` | Nth root |
| `Alt+P` | Insert pi |
| `Alt+D` | Insert differential d |
| `Shift+Alt+D` | Insert the partial-derivative symbol |
| `Tab` | Move to the next placeholder |
| `Shift+Tab` | Move to the previous placeholder |
| Arrow keys | Navigate the mathematical structure |
| `Shift`+arrow | Extend the mathematical selection |
| `Ctrl+Z` or `Cmd+Z` | Undo inside the formula field |

Experienced users can also type normal mathematical syntax or LaTeX-style commands directly. That is an optional fast path, not a requirement for formula authoring.

## Placement and saving

Under **Placement**, **Inline with text** creates a formula within the line and **On its own line** creates a display formula. **Preview** shows how the formula will look.

Formula editing is transactional. **Cancel** leaves the card unchanged. **Save formula** applies the captured formula edit as one editor change. Opening and closing the editor without changing the formula does not create a content edit.

Saved formulas display the same way in cards, practice, Tutor, and study guides.

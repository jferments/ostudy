# Artwork provenance

The artwork registered in this directory is part of the ostudy interface source and is distributed under the same project license unless an individual registry entry explicitly states otherwise.

## Registry rules

- Feature screens reference semantic artwork slots through `Artwork`; they do not import illustration files directly.
- Every slot has a functional icon or text-only fallback.
- Decorative artwork preferences affect only registered interface decoration. They never affect user-authored flashcard images, document pages, diagrams, or other educational content.
- A third-party illustration may be added only with its source, author, license, modification status, and required attribution recorded alongside the registry entry before it is committed.
- Theme variants must represent the same semantic state and must not change the available actions or accessibility description.

The initial U0–U9 artwork is project-authored or programmatically assembled from project-owned vector shapes and app-owned icons. No external font files are bundled as artwork assets.
